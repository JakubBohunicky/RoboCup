# RoboCup Junior Soccer

All generations of my RoboCup Junior soccer robots in one repo (full history of each old repo is kept).

| Folder | Event / robot |
|---|---|
| `2024/` | RoboCup 2024 (was repo `Robocup_2024`) |
| `2025_Bari/` | RoboCup 2025 Bari, gen 1 of the current robot |
| `2026_Slovakia/` | RoboCup 2026 Slovakia, gen 2 of the same robot |
| `2026_Kim-Min-seok/` | RoboCup 2026 Kim-Min-seok robot |

`_private/` (not on GitHub): other teams' code for reference.
