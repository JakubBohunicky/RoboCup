# RoboCup Junior Soccer

These are all the RoboCupJunior Soccer robots I built with my team, from our first Arduino Mega robot in 2024
to the two ESP32-S3 robots we took to the 2026 world final in Incheon.

| Folder | Event | Robot |
|---|---|---|
| [`2026_Korea/`](2026_Korea) | **RoboCup 2026 world final, Incheon: 11th of 24** | ESP32-S3, Maxon/ESCON drive, 48 line sensors, ESP-NOW role swapping ([write-up](https://developer.espressif.com/blog/2026/09/robocup-junior-soccer-robot/)) |
| [`2026_Slovakia/`](2026_Slovakia) | 2026 Slovak championship, 2nd place | Arduino Mega, gen 2 of the Bari robot |
| [`2025_Bari/`](2025_Bari) | RoboCup 2025, Bari | Arduino Mega, gen 1 |
| [`2024/`](2024) | RoboCup 2024, team XLC-Captur | Arduino Mega, our first robot |

**[2026_Korea](2026_Korea)** is the one we're proudest of.
